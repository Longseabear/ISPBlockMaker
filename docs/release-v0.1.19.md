## 변경사항

- Visualizations 상단에 리포트 공유 버튼을 추가했습니다. 공유 시 별도의 읽기 전용 HTTP 서버가 자동으로 시작되고 랜덤 토큰 링크를 생성합니다.
- LAN 주소를 자동 감지하며 Wi-Fi·유선 주소를 일반적인 VPN·가상 어댑터보다 우선합니다. 주소 선택, 포트 지정, 링크 복사를 지원합니다. 기본 포트 4311이 사용 중이면 자동으로 다음 빈 포트를 선택합니다.
- 공유본 업데이트, 개별 공유 취소, 전체 공유 중지를 지원합니다. 원본과 별도로 저장한 공유본·토큰은 재시작 후에도 유지되며 공유 서버는 기본 OFF로 시작합니다.
- 작업 서버는 loopback에 유지됩니다. 공유 서버에는 터미널·workspace·관리 API가 노출되지 않습니다.
- README에 공유 방법, 접속 조건, 저장 위치와 제한을 정리했습니다.

## 사용법과 접속 조건

Visualizations에서 공유 아이콘 → **현재 리포트 공유** → 네트워크 주소 선택 → 링크 복사를 누르세요. 특정 포트를 사용하려면 먼저 포트를 입력하고 **공유 서버 시작**을 누르세요.

공유 서버는 모든 IPv4 인터페이스(`0.0.0.0`)에서 수신합니다. 주소 선택은 복사할 링크를 바꾸는 기능입니다. 신뢰하는 로컬망에서 사용하고, 필요한 경우 Windows 방화벽에서 해당 TCP 포트를 허용하세요. 방화벽 설정을 자동 변경하지는 않습니다. 공유 링크를 가진 사람은 로그인 없이 열람할 수 있으며 통신은 HTTP입니다.

PC와 서버가 실행 중이어야 접속할 수 있습니다. 자동 만료는 없고 공유 취소로 접근을 해제합니다. IP·포트 변경 시 URL도 바뀝니다. 공유본은 서버의 로컬 runtime state에 저장되고 workspace 번들에는 포함되지 않습니다.

자체 포함 HTML과 등록된 이미지를 지원합니다. 리포트에 포함된 그림·오프라인 수식 폰트는 그대로 표시되며, 외부 파일·API 참조를 자동으로 포함하거나 변환하지 않습니다.

## 검증

전체 자동 테스트 163개가 통과했습니다. 브라우저에서 게시, 링크 복사, LAN 주소로 열람, 공유 취소와 전체 중지를 확인했습니다. 실제 다른 PC의 접속 가능 여부는 네트워크·방화벽 설정에 따라 달라집니다.

## 업데이트

Windows x64 설치파일, 오프라인 ZIP, 설치파일 SHA-256을 제공합니다. 사용자 workspace와 예제는 제외합니다. 실행 중인 작업을 마친 뒤 기존 서버를 종료하고 새 버전으로 workspace를 여세요.
