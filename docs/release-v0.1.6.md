# ISP Block Maker v0.1.6

Image Viewer의 사용자·에이전트 양방향 작업을 개선했습니다.

## 변경 사항

- 에이전트가 이미지 열기, 줌, 중심 이동, 영역 강조, 렌더링 설정 변경을 요청하고 실제 적용 여부를 확인할 수 있습니다.
- Viewer가 표시 중인 화면 PNG·좌표·설정을 자동 갱신합니다. 별도 전달 버튼 없이 에이전트가 현재 화면을 읽을 수 있습니다. 이미지 입력을 지원하는 도구/연동이 필요하며, 텍스트 출력만으로 모델에 이미지가 전달되지는 않습니다.
- 현재 화면은 최신 파일 하나만 유지합니다. 화면 갱신이 10초 이상 끊기면 오래된 화면의 이미지 조회를 거부합니다.
- 마우스 휠로 커서 중심 확대·축소, Shift+드래그 또는 가운데 버튼으로 이동할 수 있습니다.
- 오른쪽 크롭 패널 너비를 드래그로 조절하고 기억합니다.
- Shift+클릭으로 크롭 범위를 선택하거나 체크박스로 개별 선택한 뒤 한 번에 전달합니다. 좌표·저장된 설명·파일 경로가 포함됩니다.
- 크롭 저장·다운로드·제거 버튼을 아이콘으로 정리했습니다. 크롭과 설명은 명시적으로 저장합니다.
- 터미널의 기본 Ctrl+V 붙여넣기, 선택 영역 Ctrl+C 복사, Ctrl+Shift+A 전체 선택을 지원합니다. 선택이 없는 Ctrl+C는 실행 중단으로 유지합니다.
- 새 RAW 이미지의 기본 표시를 Simple ISP로 설정했습니다. Bayer/Tetra·감마 미리보기이며 원본 RAW는 변경하지 않습니다.

## 설치 및 실행

Windows x64용 `ISPBlockMaker-Setup.exe`를 실행하세요. Node와 실행 의존성이 포함되며 예제·사용자 워크스페이스는 포함하지 않습니다. 설치 후 새 터미널에서 작업 폴더로 이동해 `isp-block-maker .`를 실행하세요.

Git, Python, 에이전트 CLI와 모델 접속 환경은 별도입니다. 기존 프로젝트의 사용자 스킬은 자동 덮어쓰지 않으므로 새 Viewer 명령 사용법을 반영하려면 프로젝트 스킬도 갱신하세요. 설치 파일은 코드 서명되지 않았으며 SHA-256 체크섬을 제공합니다.
