# v0.1.40 · 셸 MCP 자동 연결과 탭 탐색 수정

앱의 일반 Terminal과 Terminal Hub에서 `claude` 또는 `codex`를 직접 입력하면 해당 워크스페이스의 MCP 설정을 자동 전달합니다. 기본 Shell을 중지하거나 비활성화된 에이전트 드롭다운을 바꿀 필요가 없습니다.

- 프로젝트 전용 PATH 실행기를 사용하며 사용자 전역 설정은 변경하지 않습니다. 기존 옵션과 종료 코드를 전달하고, Claude용 임시 설정 파일은 정상 종료 시 정리합니다.
- 직접 실행한 에이전트는 MCP 초기화마다 독립된 세션/Terminal Hub 소유권을 받습니다. 기존 에이전트 토큰을 상속하지 않습니다.
- Terminal Hub를 메인 뷰로 복원했습니다. Terminal 모드에서 위 Hub와 아래 에이전트 터미널을 동시에 볼 수 있습니다.
- Alt+←/→는 Interaction 대화 또는 터미널의 이전/다음 탭으로 이동합니다. 포커스가 있는 영역을 우선하며, 포커스가 밖이면 현재 모드의 대화/Agent CLI를 선택합니다. Alt+PageUp/PageDown도 유지합니다.
- Alt+1~5와 화면 순서를 Board → Code → Report → Image Viewer → Terminal Hub로 통일했습니다. 채팅 iframe과 로컬 HTML 리포트도 같은 키를 전달합니다.

## 검증

전체 회귀 테스트 **304개 통과**.

MCP 설정/인증, 외부 세션 분리, 소유권 거부, 도구 실행/재시도, 체크포인트 복원, 스킬 업데이트, 터미널과 키보드 탐색을 전체 회귀 테스트로 검사했습니다. 실제 Terminal Hub PTY에서 CLI 대역을 실행해 주입된 설정으로 MCP 초기화와 워크스페이스 조회를 수행하고, 반복 실행의 세션 ID가 다름을 확인했습니다. 이 테스트는 상용 모델 호출이나 실제 SSH 접속을 수행하지 않습니다.

## 업데이트 후

워크스페이스 서버를 새 버전으로 재시작하고 새 터미널을 여세요. 실행 중인 셸에는 PATH와 연결 설정이 소급 적용되지 않습니다. CLI는 서버의 원래 PATH에서 찾으므로 Claude/Codex 설치 후 서버 재시작이 필요할 수 있습니다.

앱 밖에서 연 셸이나 실행파일 절대경로 호출은 자동 실행기를 거치지 않습니다. 워크스페이스 밖으로 이동한 경우 잘못된 프로젝트 연결을 방지하기 위해 실행을 거부합니다. 기존 사용자 수정 스킬은 보존되며 업데이트 후보는 `.isp/skill-updates/`에 저장됩니다.
