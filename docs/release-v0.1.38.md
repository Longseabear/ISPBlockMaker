# v0.1.38 · 기존 서브모듈 프로젝트 시작 오류 수정

- 이미 `project/` 구조로 변환된 워크스페이스에서 Git 서브모듈 때문에 서버가 시작되지 않던 오류를 수정했습니다.
- 실제 파일 이동이 없는 재열기·기존 구조 인식에서는 서브모듈의 자동 이동 금지 검사를 적용하지 않습니다. 초기화된 서브모듈과 아직 체크아웃하지 않은 gitlink 모두 포함합니다.
- 기존 구조를 실제로 이동해야 하는 마이그레이션은 이전과 동일하게 보호합니다. Git 이력, 스테이징 인덱스, `.gitmodules`, 서브모듈 Git 연결 파일을 보존합니다.

## 설치

작업을 저장하고 기존 앱 서버를 종료한 뒤 새 설치 파일을 실행하세요. 문제가 있던 프로젝트를 그대로 다시 열면 됩니다. 프로젝트 재마이그레이션, `.isp` 삭제, 서브모듈 삭제는 필요하지 않습니다.

## 검증

- 전체 자동 테스트 288개 통과(동시 실행 수 4).
- 프로젝트 구조 관련 테스트 13개 통과: 서브모듈이 있는 변환 완료 폴더의 재열기·구조 인식과 Git 데이터 보존 확인.
- Windows 배포본의 시작 검사 및 실제 서브모듈 워크스페이스 서버 시작 확인. Git HEAD·인덱스·서브모듈 연결 파일 보존 확인.
- TypeScript 검사, 프로덕션 빌드, Windows 설치 EXE·오프라인 ZIP·SHA-256 제공.
