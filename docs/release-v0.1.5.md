# ISP Block Maker v0.1.5

Windows x64용 Visualization 및 Image Viewer 업데이트입니다.

## 변경 사항

- Visualization의 플로팅 확장 버튼으로 터미널·사이드바·헤더를 잠시 접고, 다시 누르면 기존 배치를 복원합니다. 터미널 세션은 유지됩니다.
- 이미지 영역 선택 후 **크롭 추가** 버튼을 누르면 오른쪽 목록에 여러 크롭을 보관할 수 있습니다.
- 크롭마다 설명을 작성하고 **설명 저장** 버튼으로 저장합니다. 자동 저장하지 않습니다.
- 크롭 항목을 개별 제거할 수 있습니다. 해당 크롭의 파일·미리보기·메타데이터를 삭제하며 원본 이미지와 다른 크롭은 유지합니다.
- Bayer/Tetra 픽셀 정렬과 크롭 좌표 정보를 유지합니다.
- 에이전트가 워크스페이스 밖의 이미지도 읽기 전용으로 가져올 수 있습니다.

## 설치 및 실행

`ISPBlockMaker-Setup.exe`를 실행하세요. Node와 서버 의존성을 포함하며 예제·사용자 워크스페이스는 포함하지 않습니다. 설치 후 새 터미널에서 작업 폴더로 이동해 `isp-block-maker .`를 실행하세요.

Git, Python, 에이전트 CLI와 모델 접속 환경은 별도입니다. 설치 파일은 코드 서명되지 않았으며 SHA-256 체크섬을 제공합니다. 기존 프로젝트의 사용자 스킬은 자동으로 덮어쓰지 않습니다.
