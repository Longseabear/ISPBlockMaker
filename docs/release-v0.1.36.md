# v0.1.36 · HTML 자동 포함과 선택형 번들 공유

- HTML 등록·수정 시 로컬 이미지, srcset, CSS, 중첩 일반/미디어 CSS import, 폰트 및 일반 JavaScript를 자동으로 포함합니다. 원본 파일은 유지하고 등록 사본만 변환합니다.
- 수정 시 원본·포함 자산 해시를 갱신하며, 리포트 ID와 실험 연결은 유지합니다. 별도 report-build와 화면 품질 검사 단계는 필요 없습니다.
- 번들은 그래프·블록 명세를 필수로 유지하면서 구현 코드·스킬과 작업 기록을 각각 선택할 수 있습니다. 코드 제외 시 Git 이력도 제외합니다.
- 로컬 MCP에 preview_bundle / pack_bundle을 추가했습니다. 미리보기 내용이 바뀌면 재확인하며, 같은 요청 ID 재시도는 중복 생성하지 않습니다.
- 새 대화를 추가할 때 기존 탭과 작성 중인 내용을 유지합니다. 탭 전환과 최대 4개 분할 표시를 분리했습니다.

## 지원 범위

HTML 파일과 참조 자산은 workspace 내부에 있어야 합니다. 외부 URL을 내려받지 않습니다. ES 모듈·런타임 fetch 등 애플리케이션 의존성은 미리 번들링해야 합니다. 최종 등록 파일은 10 MiB 이하입니다. 그래프 설명이나 선택한 리포트에 직접 작성된 코드는 코드 제외 공유에서도 유지됩니다.

## 설치

작업을 저장하고 기존 서버를 종료한 뒤 ISPBlockMaker-Setup.exe를 설치하세요. 작업 폴더는 보존됩니다. 서버와 에이전트를 다시 시작하면 새 MCP 도구와 갱신된 기본 스킬을 사용할 수 있습니다. 사용자 수정 스킬은 보존하고 업데이트 후보로 제공합니다.
