## 변경사항

- 에이전트가 Viewer API/CLI로 로드된 RAW의 비트 깊이, 픽셀 배열, Bayer/Tetra/TetraSquare, LSB/MSB 정렬을 변경할 수 있습니다.
- `zoomPercent`로 화면에 표시되는 원본 기준 확대율을 지정하고, 원본 좌표로 확대 중심을 설정합니다. 화면 맞춤, 렌더링 모드·감마·표시 범위, 픽셀 값 표시와 영역 강조도 지원합니다.
- `isp viewer-control options.json --wait 15`는 UI 적용 응답을 기다리고 성공 여부를 반환합니다. 잘못된 설정과 충돌하는 배율 옵션은 거부합니다.
- RAW 해석 변경은 새 이미지 또는 동일 규격의 기존 이미지로 저장하며, 이전 이미지와 저장된 크롭을 보존합니다.
- Viewer 스킬과 README에 API 사용법, 배율 단위, 적용 상태 확인 방법을 추가했습니다.

## 업데이트

기존 서버에서 작업을 마친 뒤 종료하고 새 버전으로 workspace를 여세요. 기존 터미널 프로세스는 서버 종료 시 종료되므로 작업을 먼저 마쳐주세요. 페이지 새로고침만으로 서버 API가 업데이트되지는 않습니다.

## 배포

Windows x64 설치파일, 오프라인 ZIP, 설치파일 SHA-256을 제공합니다. Node 및 서버 의존성을 포함하며 사용자 workspace와 예제는 제외합니다.

## 검증

전체 테스트 158개, TypeScript/Vite 빌드, Windows 패키지 시작 검사를 통과했습니다. 실제 브라우저에서 RAW 설정·400% 확대·중심 좌표·픽셀 표시·Simple ISP·감마·화면 맞춤을 적용하고 현재 화면 메타데이터와 대조했습니다. 빌드와 병행한 첫 테스트에서는 기존 레시피 프로세스 종료 검사가 한 번 실패했으며, 해당 묶음 단독 재검사와 빌드 종료 후 전체 재검사는 모두 통과했습니다.
