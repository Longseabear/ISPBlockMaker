# ISP Block Maker v0.1.2

Windows x64용 업데이트입니다.

## 변경 사항

- 에이전트 설명 맨 위에 **Input 설명 / Output 설명**을 추가했습니다. 입력·출력의 의미, 형태, 범위, 전제조건, 예시와 해석 방법을 별도로 저장합니다.
- **자유 메모 · Agent notes**를 추가했습니다. 설계 의도, 대안, 주의사항, 미해결 질문 등 분류되지 않는 지식을 자유롭게 기록할 수 있습니다.
- 프로젝트 스킬에 입력·출력 중심 설명과 자유 형식 지식 작성 지침을 추가했습니다.
- 왼쪽 메뉴의 Documentation을 JOB Queue 아래로 옮겼습니다.
- 기존 그래프와 설명을 보존하며 새 항목은 빈 값으로 처리합니다.

## 설치 및 실행

`ISPBlockMaker-Setup.exe`를 실행하세요. Windows x64용 Node와 실행 의존성을 포함하므로 별도 npm 설치가 필요하지 않습니다. 예제와 사용자 작업 데이터는 포함하지 않습니다.

설치 후 새 터미널에서 작업 폴더로 이동해 `isp-block-maker .`를 실행하세요. Git, Python, 에이전트 CLI와 모델 접속 환경은 별도로 준비합니다. 설치파일은 코드 서명되지 않았으며 SHA-256 파일을 함께 제공합니다.

기존 프로젝트의 스킬은 자동으로 덮어쓰지 않습니다. 새 에이전트 작성 지침을 적용하려면 프로젝트의 `.agents/skills/isp-block-maker/SKILL.md`를 새 템플릿 기준으로 병합하세요. 새 프로젝트에는 새 스킬이 준비됩니다.
