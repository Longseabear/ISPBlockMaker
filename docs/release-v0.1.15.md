## 변경사항

- Project Skills 탭: 프로젝트 전용 스킬 생성·편집·검색·삭제, 저장 상태와 기본 스킬 읽기 전용 표시. 참조 문서와 보조 스크립트를 함께 관리합니다.
- 에이전트 CLI의 스킬 조회·등록·수정과 스킬화 판단 가이드를 추가했습니다. 반복되는 절차는 스킬로 남기고 기존 스킬 보완을 우선합니다.
- 스킬 전용 번들 내보내기·내용 미리보기·선택 가져오기를 지원합니다. 전체 프로젝트 번들에도 스킬이 포함됩니다. 같은 이름은 명시적으로 선택하고 수정 충돌을 검사합니다.
- workspace 내부 project/의 그래프·구현 Git과 .isp의 로컬 상태를 분리하고 작업 시도·체크포인트 추적을 추가했습니다.
- Viewer의 다중 크롭 묶음, 분석 정보, 픽셀 값, RAW 픽셀 설정, 크롭 대기 명령 및 확대 중 외곽선 표시를 개선했습니다.
- 블록 Reference I/O를 등록·확인·공유할 수 있습니다. Python과 C-model의 일대일 대응은 강제하지 않습니다.
- 프로젝트 번들 v2: 시각화 선택, 데이터·Viewer·Git 이력 선택, 새 폴더 복원과 백업 후 덮어쓰기. 기존 v1 번들도 읽습니다.
- README, 프로젝트 로컬 스킬 가이드, GitHub Pages 사용 안내를 업데이트했습니다.

## 업데이트

이전 서버를 종료한 뒤 새 버전으로 workspace를 여세요. 기존 데이터는 보존하며 로컬 기본 스킬을 갱신합니다. 직접 수정한 기본 가이드는 보존하고 새 템플릿을 .isp/skill-updates에 준비합니다. 에이전트를 새 세션으로 시작하거나 isp skills로 프로젝트 스킬을 확인하세요.

## 배포

Windows x64 설치파일, 오프라인 ZIP, SHA-256. Node와 서버 의존성 포함, 사용자 workspace와 예제 제외. Git, Python과 프로젝트 패키지, 에이전트 CLI는 별도로 준비하세요.

## 검증

전체 테스트 115개, TypeScript/Vite 빌드, Project Skills UI 검색·표시 확인을 통과했습니다. Windows x64 패키지의 포함된 Node·서버 의존성·네이티브 터미널 시작 검사와 설치파일 SHA-256을 확인했습니다. 배포 패키지에는 사용자 workspace를 포함하지 않습니다.
