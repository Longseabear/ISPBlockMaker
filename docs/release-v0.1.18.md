## 변경사항

- Visualizations의 HTML 리포트 생성기에 `math` 섹션을 추가했습니다. LaTeX 문법으로 분수, 합 기호, 행렬 등 수식을 작성할 수 있습니다.
- KaTeX로 서버에서 수식을 미리 렌더링하고 CSS·WOFF2 폰트·라이선스를 HTML에 포함합니다. 공유한 리포트도 인터넷, CDN, 별도 LaTeX 설치 없이 열 수 있습니다.
- 수식이 있는 리포트에만 폰트·스타일 약 369KB를 한 번 추가합니다. 수식마다 중복 삽입하지 않습니다.
- 수식 길이와 매크로 확장 범위를 제한하고 링크·HTML·외부 리소스를 차단합니다. 잘못된 수식은 오류로 알려줍니다.
- Windows 패키지에 KaTeX 의존성을 포함하도록 설정했습니다. README, 시각화 스킬, 리포트 생성 가이드에 JSON 예시와 사용법을 추가했습니다.

## 사용법

`isp report-build`의 JSON 명세에서 다음과 같이 섹션을 추가하세요.

```json
{"type":"math","title":"Variance","latex":"\\sigma^2 = \\frac{1}{N}\\sum_{i=1}^{N}(x_i-\\mu)^2","description":"Pixel values in DN; N is the sample count."}
```

생성한 HTML을 기존처럼 artifact로 등록하고 Visualizations에 표시합니다. 일반 문장의 `$$...$$`를 자동 변환하는 기능은 아닙니다. 수식 렌더링은 계산이나 수학적 정확성 검증을 수행하지 않습니다.

## 검증

전체 자동 테스트 161개가 통과했습니다. Windows 배포 패키지의 시작 검사(Node·의존성·폴더 접근·터미널)와 포함된 KaTeX의 수식·폰트·라이선스 로딩을 확인했습니다. 브라우저에서는 실제 리포트와 같은 CSP 조건에서 분수·합·행렬 표시를 검증했습니다.

## 업데이트와 배포

Windows x64 설치파일, 오프라인 ZIP과 설치파일 SHA-256을 제공합니다. 런타임과 서버 의존성을 포함하며 사용자 workspace와 예제는 제외합니다. 실행 중인 작업을 마친 뒤 기존 서버를 종료하고 새 버전으로 workspace를 여세요.
