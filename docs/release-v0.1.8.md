# ISP Block Maker v0.1.8

Image Viewer의 공간 활용과 에이전트 이미지 열기 흐름을 개선한 Windows x64 릴리즈입니다.

## 변경 사항

- 오른쪽/가운데 버튼 또는 Shift+드래그로 이미지를 직접 이동합니다. 이미지보다 큰 여백에서도 이동할 수 있으며, 휠은 마우스 위치를 중심으로 확대합니다.
- 해상도, 이미지 해석 조건, 에이전트 안내를 오른쪽 아래 접이식 정보 패널에 모았습니다. 크롭 입력은 오른쪽 패널로 옮겨 터미널과 함께 사용하는 이미지 공간을 확보했습니다.
- 이동·확대 후 현재 View 공유 좌표를 실제 보이는 이미지 영역에 맞춥니다. 이미지가 화면 밖으로 나가면 이전 화면을 최신 화면으로 제공하지 않습니다.
- `viewer-open 파일 --spec 설정.json`으로 RAW 등록과 표시 요청을 함께 수행하고, 표시 결과를 확인할 수 있습니다. 동일한 파일과 설정은 재사용합니다.
- RAW의 비트 정렬, CFA 배열과 그룹, 행 간격, 렌더링 조건을 확인할 수 있습니다. Simple ISP의 그룹 평균 및 bilinear 보간 방식도 표시합니다.

## 설치 및 실행

`ISPBlockMaker-Setup.exe`를 실행하세요. Node와 실행 의존성이 포함되며 예제·사용자 워크스페이스는 포함하지 않습니다. 설치 후 새 터미널에서 작업 폴더로 이동해 `isp-block-maker .`를 실행하세요.

Git, Python, 에이전트 CLI와 모델 접속 환경은 별도입니다. 설치 파일은 코드 서명되지 않았으며 SHA-256 체크섬을 제공합니다.
