# 기본 MCP, 검색, LAN 공유

## 로컬 에이전트 연결

ISP Block Maker에서 새로 실행하는 Claude Code/Codex의 Interaction 및 Terminal 세션에는 `isp-workspace` MCP를 런타임 설정으로 추가한다. 같은 앱 서버의 인증된 `/mcp`를 사용하며 별도 공용 서버는 필요 없다. 전역 에이전트 설정이나 회사 Claude Code 실행 파일을 바꾸지 않는다. 이미 실행 중인 세션에는 소급 적용되지 않는다.

배포 패키지에 MCP SDK와 SQLite 검색에 필요한 Node 런타임을 포함한다. 사용자는 MCP SDK를 별도 설치하지 않는다. 실제 Claude Code/Codex 실행 파일과 로그인은 기존 환경을 사용한다. 사용자가 등록하는 다른 MCP 서버의 실행 도구까지 포함하는 것은 아니다.

스킬은 블록 작성법과 작업 절차를 안내하고 MCP는 구조화된 조회·변경을 수행한다. 도구 목록에 없는 기능은 기존 CLI를 사용한다. 관리되는 graph JSON이나 실행 상태를 직접 수정하지 않는다. 상세 도구 목록과 작성 규칙은 [관리 스킬](../templates/project/.agents/skills/isp-block-maker/mcp-search.md)에 있다.

## 검색

사이드바의 **Workspace Search**에서 검색어, 다이어그램 범위, 단어 조건을 선택한다. 결과를 누르면 원문을 읽고 **Board에서 보기**로 연결된 블록을 연다.

- `search_workspace`: BM25 순위, 따옴표 구문, 모든 단어/하나 이상 조건, 다이어그램·블록 필터.
- `read_document`: 결과의 문서 ID와 해시로 원문 일부를 읽는다. 변경된 문서는 다시 검색한다.
- `count_matches`: 일치한 문서 수를 센다. 단어 출현 횟수나 대화 수가 아니다.
- `retrieve_context`: 근거 구절과 관련 블록·인접 계약·연결을 제한된 응답 크기로 묶는다.

다이어그램과 블록 정의, 블록 폴더의 README 및 문서, 명시적으로 연결된 지원 형식 소스, 로컬 JOB을 색인한다. 채팅 기록과 전체 프로젝트 파일을 재귀적으로 수집하지 않는다. 이미지·대용량 데이터셋도 텍스트 색인에 넣지 않는다. 결과의 경로/필드·행·해시를 근거로 사용하고, 결과 없음은 색인 범위 안에서 일치 항목이 없다는 뜻으로 해석한다.

색인은 워크스페이스 로컬 검색 캐시이며 원본을 대체하지 않는다. 삭제·변경된 문서는 다음 조회 때 반영된다. 파일 크기 제한 등으로 제외된 자료의 내용까지 검색했다고 주장하지 않는다.

## 로컬망에 읽기 공유

1. **MCP Servers**의 공유 영역을 연다.
2. 기본 다이어그램/블록 문서 외에 공개할 소스와 이미지를 개별 선택한다. 두 선택 모두 기본은 비어 있다.
3. 공유를 시작하고 상대방이 접근할 수 있는 LAN 주소의 URL을 복사한다.
4. 상대방은 Streamable HTTP MCP 클라이언트에 URL을 등록해 검색·조회한다.

앱과 같은 프로세스가 별도 공유 리스너를 연다. 기본 포트는 4312이며 사용 중이면 다음 포트를 시도한다. 웹 편집기와 실행 API는 localhost에 유지한다. 공유 MCP에는 변경·터미널 실행·하네스 실행 도구와 로컬 JOB을 제공하지 않는다. 공개할 설명 자체에 민감한 내용을 넣지 않았는지도 확인한다.

URL을 가진 사람에게 읽기 접근을 허용하는 HTTP 공유이므로 신뢰하는 로컬망에서 사용한다. **URL 재발급**으로 기존 URL을 폐기하고 **공유 중지**로 접근을 종료한다. 공개 범위를 바꾸려면 중지 후 다시 시작한다. 서버 재시작 또는 워크스페이스 전환 후에는 공유가 꺼진다. Windows 방화벽은 자동 변경하지 않는다.

선택한 이미지는 명시적인 이미지 읽기 도구로만 모델에 전달한다. 로컬 Image Viewer 표시·픽셀 통계 도구는 텍스트 메타데이터를 반환하므로 이미지 입력을 지원하지 않는 모델에서도 사용할 수 있다.

## 변경과 재시도

변경 도구는 `request_id`로 중복 실행을 방지한다. 같은 작업의 재전송에는 같은 ID와 입력을 사용한다. 그래프 변경은 읽었던 revision, Runs 실행은 확인한 recipe hash, 하네스 제어는 현재 run version을 요구한다. 응답이 불확실하면 현재 상태를 확인하고 재실행 여부를 결정한다. 연결 종료를 작업 완료나 취소로 해석하지 않는다.

클라이언트에서 에이전트에 작업을 보내려면 별도의 [Personal Agent API](personal-agent-api.md)를 켜고 전용 토큰을 사용한다. 이 읽기 공유 URL로 에이전트 실행을 요청할 수는 없다.
