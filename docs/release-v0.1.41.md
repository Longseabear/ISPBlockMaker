# v0.1.41 · Terminal Hub 키 연결과 자동 입력 우선권

Terminal Hub의 에이전트 인계 드롭다운과 수동 조작 전환을 제거했습니다. `Shared Terminal Key 복사`로 키를 전달하면 에이전트가 `join_shared_terminal`로 기존 셸에 연결합니다. 기존 SSH·서버 프로세스를 재시작하지 않습니다. 수동 인계 MCP 도구와 REST 경로도 제거하고 문서·스킬을 갱신했습니다.

- 사용자가 입력하면 즉시 사용자 우선이며 이전 제어 버전의 에이전트 입력은 거부됩니다. 작성 중인 줄은 계속 보호됩니다. Enter/Ctrl+C/Ctrl+D로 제출·취소 후 2초간 추가 입력이 없으면 기존 연결 에이전트가 최신 상태와 출력을 읽고 재개할 수 있습니다. 명령 완료를 추정하거나 실행 프로세스를 자동 중지하지 않습니다.
- 키는 사용자 UI에서만 발급하며 목록·출력·알림에 노출하지 않습니다. 새 키를 만들면 이전 키가 무효화되고, 다른 에이전트의 키 재사용을 거부합니다. 사용자 입력 후 같은 에이전트는 새 키 없이 재개합니다.
- 일반 Terminal과 Hub에 같은 Windows / SSH·Linux 키 입력 설정을 추가했습니다. SSH·Linux 모드에서는 Ctrl+Backspace를 Ctrl+W로 전송해 일반 원격 셸의 단어 삭제에 대응합니다. 로컬 cmd는 기존 Ctrl+H를 유지합니다. 원격 프로그램의 커스텀 키 바인딩은 별도입니다.
- MCP 인자 문서를 실제 스키마와 맞추고 문서 예제를 검증하는 테스트를 추가했습니다.

## 버전 확인

```text
isp-block-maker --version
isp --version
isp version
```

첫 두 명령은 서버 연결 없이 해당 실행 파일/CLI의 패키지 버전을 표시합니다. `isp version`은 워크스페이스 CLI와 실행 중인 서버 버전, 서버 위치·PID, 일치 여부를 반환합니다. 연결 실패는 서버 버전 null과 오류로 표시합니다. MCP에서는 `get_runtime_version`을 사용합니다.

## 업데이트 후

프로젝트 서버를 완전히 종료하고 새 버전으로 다시 여세요. 외부 MCP 클라이언트를 재연결해 제거·추가된 도구 목록을 갱신하고 새 터미널을 사용하세요. 기존 사용자 수정 스킬은 보존되며 업데이트 후보는 `.isp/skill-updates/`에 저장됩니다. 원격 SSH 호스트의 실제 키 설정과 모델 실행은 로컬 회귀 테스트 범위에 포함하지 않습니다.

## 검증

전체 테스트 310개 통과. 실제 MCP/PTY 키 연결·입력 우선권·구 인계 경로 제거와 문서 예제 스키마를 검증했습니다. 배포 패키지의 시작 검사 및 오프라인 버전 명령, 설치파일 체크섬도 확인했습니다.
