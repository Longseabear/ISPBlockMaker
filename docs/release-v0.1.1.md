# ISP Block Maker v0.1.1

Windows x64 설치파일에 최신 노드 설명 분리 기능을 포함했습니다.

- **Node Description**: 그래프 카드에 표시할 짧은 요약.
- **Node Detail**: 별도로 저장되는 사용자용 상세 설명·예시·주의사항.
- **에이전트 설명**: 구현·검증에 적합한 언어, 수식, 의사코드로 작성하는 기술 명세.
- 프로젝트 스킬에 세 영역의 작성 기준과 동기화 규칙을 반영했습니다.
- 기존 설명은 보존하며 이전 그래프에 Detail이 없으면 빈 값으로 처리합니다.

## 설치 및 실행

`ISPBlockMaker-Setup.exe`를 실행해 설치하세요. Node와 실행 의존성이 포함되며 예제와 사용자 작업 데이터는 포함하지 않습니다. 설치 후 새 터미널에서 작업 폴더로 이동해 `isp-block-maker .`를 실행하세요.

기존 프로젝트의 사용자 수정 스킬은 자동으로 덮어쓰지 않습니다. 기존 프로젝트에도 새 작성 지침을 적용하려면 해당 프로젝트의 `.agents/skills/isp-block-maker/SKILL.md`를 새 템플릿 기준으로 병합하세요. 새 프로젝트에는 새 스킬이 준비됩니다.

Windows x64용이며 코드 서명되지 않았습니다. Git, Python, 에이전트 CLI와 모델 접속 환경은 별도입니다. 체크섬 파일로 설치파일의 SHA-256을 확인할 수 있습니다.
