# v0.1.23 · 번들 데이터 선택, 업데이트 안내, GPU UI 확장

- 번들 미리보기에서 데이터 파일과 Reference I/O 세트별 용량 및 포함 여부를 선택할 수 있습니다. 범주별 합계와 참조 세트 내부 파일 용량을 표시합니다.
- 파일당 256 MiB를 초과해도 미리보기 목록을 유지하고, 해당 데이터를 제외한 뒤 저장할 수 있습니다. 전체 2 GiB 제한은 유지됩니다.
- 앱에서 최신 안정 릴리스를 확인하고 설치 안내 또는 설치 파일로 바로 이동할 수 있습니다. 자동 설치는 수행하지 않습니다.
- Windows 내장 터미널이 cmd임을 안내하고 PowerShell에서 cmd 전용 명령이 실패할 때 전환 방법을 제공합니다.
- GPU 확장에서 파라미터 그룹, 슬라이더·숫자·선택 컨트롤과 가로·세로·출력 집중 배치를 지정할 수 있습니다. 실행 가능한 GLSL 예제와 에이전트 지침을 제공합니다.

GPU simulator는 RGBA8 WebGL2 미리보기입니다. Python 자동 변환이나 RAW 정밀도 검증은 지원하지 않습니다.

## 설치

`ISPBlockMaker-Setup.exe`를 다운로드하세요. 작업을 저장하고 기존 앱과 서버를 종료한 뒤 설치하고 다시 실행하세요. Node 런타임과 실행 의존성이 포함됩니다. 작업 폴더는 설치 파일에 포함되지 않습니다.

설치 파일의 SHA-256은 함께 제공하는 `.sha256` 파일로 확인할 수 있습니다. 오프라인 ZIP도 제공합니다.
