## 변경사항

- Image Viewer: RAW와 BMP를 확대하면 보이는 영역의 원본 픽셀을 타일로 읽어 WebGL2로 렌더링합니다. 다운샘플링된 미리보기를 늘리던 방식에서 원본 픽셀 기반 확대·크롭으로 개선했습니다.
- 큰 영상도 전체 프레임을 탐색하며, RAW는 Bayer 표시가 기본입니다. 1:1 확대, 원본 좌표·픽셀 값 확인, 현재 화면 전달을 지원합니다.
- 원본 타일을 읽는 동안 정밀 크롭을 잠시 제한하고 렌더링 오류를 표시합니다. 원본 확대에는 WebGL2를 지원하는 브라우저 환경이 필요합니다.
- 브라우저 새로고침 후 실행 중인 터미널에 재연결하고 최근 출력을 복원합니다. 중복 연결은 입력 소유권을 전환합니다. 서버 종료 후 프로세스 복원은 지원하지 않습니다.
- 에이전트 도구: 그래프·구현 연결 점검, 재사용 가능한 실행 레시피, 로컬 HTML 리포트 빌드를 추가했습니다.
- ISP 개발·시각화 스킬을 방법론 중심으로 정리했습니다. 변경 영향, 선택적 검증, 그래프 설명과 실제 구현의 일치 여부를 의미 있는 작업 시점에 확인하도록 안내합니다.
- workspace의 AGENTS.md와 CLAUDE.md에 공통 작업 가이드를 설치하며 기존 사용자 내용을 보존합니다.

## 업데이트

실행 중인 작업을 마친 뒤 이전 서버를 종료하고 새 버전으로 workspace를 여세요. 기본 스킬은 갱신되며 직접 수정한 가이드는 보존하고 업데이트 후보를 제공합니다.

## 배포

Windows x64 설치파일, 오프라인 ZIP, 설치파일 SHA-256을 제공합니다. Node와 서버 의존성을 포함하며 사용자 workspace와 예제는 제외합니다. Git, Python 및 프로젝트 패키지, 에이전트 CLI는 별도로 준비하세요.

## 검증

전체 테스트 158개, TypeScript/Vite 빌드, Windows 설치파일 빌드를 통과했습니다. 패키지에 포함된 Node·서버 의존성·네이티브 터미널 시작 검사와 설치파일 SHA-256을 확인했습니다. WebGL 렌더링은 48개 CFA 패턴·그룹·표시 모드 조합으로 CPU 결과와 비교했으며, 8bit 표시 값 차이는 최대 1이었습니다.
